# Val 길이 설계 노트 — 다음 롤링에서 Val 6개월 → 12개월?

작성 2026-11-10 · claude (AI) · 사람 검토용 설계 노트 (결정 아님) · 관문 설정 v1 · 비용 코인원 v2
· 코드 `src/btc_quant/research/calibration_study.py` (`--val-months`, `--val-end`, `--full-low`, `--full-vlow`, `--markets`,
`--strengths` — 모두 기본 꺼짐, 이번에 추가)

**근거는 합성 시장뿐이다.** 실제 캠페인 결과, Val 수치, 잠금 구간 데이터는 쓰지 않았다. `config/splits.yaml`·`gates.yaml` 은
바꾸지 않았다. Val 롤링은 사람이 편집한다(상한 도달 시).

## 요약 (권고)

1. **통계 부분만 보면 12개월 Val 이 분명히 낫다. 비용은 거의 없다.**
   - 저회전(하루 0.2–1회)에서 G6 의 '평균 > 0' 증거, 곧 Sharpe > 0, stress Sharpe > 0, 누적 Holm 을 합친 통과율이 크게 오른다.
     참 Sharpe 2 기준으로 k=1 에서 0.56 → 0.74, k=3 에서 0.32 → 0.55, k=10 에서 0.16 → 0.34 다 (G6 단계 MC, f = 0.5/일).
   - 전체 파이프라인을 같은 시장끼리 짝지어 돌린 결과도 같다. 저회전 32 시장(Sharpe 2·3)에서 "통계 조건만" 통과가
     16 → 23 (k=1), 7 → 14 (k=5) 다. 12개월에서만 통과한 시장이 7곳, 6개월에서만 통과한 시장은 0곳이다.
   - 오탐은 늘지 않는다. Holm 은 Val 길이와 무관하게 정확하고, 귀무 시장에서 통계만 통과하는 비율은 ≈ α/k 다.
     Dev 가 6개월 짧아지는 비용(G1·G4·G5)은 하루 ≥ 0.2회 전략에서 작다.
2. **그러나 지금 G6 의 낙폭 조건 두 개는 Val 전체 경로에 걸려 있다.** primary MDD ≤ 20% 와 거래당 MC MDD95 ≤ 20% 다.
   낙폭은 경로가 길수록 깊어진다. 그래서 **조건을 그대로 두고 Val 만 12개월로 늘리면 G6 통과가 오히려 준다.**
   - 저회전 짝 비교(현재 규칙, Sharpe 2·3, 32 시장)에서 validated 는 3 → 0 이었다.
   - MC 에서 절반 포지션·f 0.5·Sharpe 2 의 k=1 통과율은 0.63 → 0.46 이다.
   - 12개월이 이기는 것은 누적 Holm 의 k 가 클 때(k ≥ 10)뿐이다.
3. **권고: 12개월 Val 은 'MDD 조건을 경로 길이에 맞게 바꾸는 것'과 묶어서만 채택한다.**
   예: MC MDD95 를 6개월 상당 거래 수로 재표본한다(경로 길이 = Val 거래 수 × 6/Val 개월).
   또는 primary MDD 를 '6개월 롤링 창 최대 낙폭'으로 본다. 이것은 class ③ 위험 선호 결정이라 사람이 정한다.
   이 변경 없이 12개월로 늘릴 거라면 **6개월을 유지**하는 편이 낫다.
   회전율이 중간(하루 ≈ 5회)인 전략에서는 Val 길이가 큰 차이를 만들지 않는다. 묶는 조건이 stress Sharpe 이고, 그 모평균 ≈ 참 Sharpe − 2.4~3.3 이기 때문이다.
   파이프라인 짝 비교에서 validated 는 참 Sharpe 3 에서 4/8 → 2/8, Sharpe 4 에서 8/8 → 8/8 이었다.
4. **Val 길이와 별개로 가장 크게 묶는 조건**: 저회전·장기 보유(1~3일) 스펙은 전액 포지션으로 평가하는 MC MDD95 ≤ 20% 에서
   대부분 떨어진다. Val 6개월에서도 그렇다. MC 에서 참 Sharpe 2·f 0.5 의 MC 통과율은 11%, 파이프라인 S* 대표는 MC MDD95 중앙값 0.30 이다.
   낙폭 기준이 포지션 크기에 의존한다는 점을 사람이 알고 있어야 한다(정보 전용, 기준 변경 제안 아님).
5. **잠금 구간**: 다음 잠금 롤링에서 12개월 Val 을 만들 깨끗한 방법은 없다.
   (a) val1+lb1 을 합치면 이미 쓴 val1 을 재사용하게 된다. (b) 깨끗한 12개월을 기다리면 롤링이 2027-11 이후로 미뤄진다.
   (a)를 택한다면 val1 의 Holm 이력을 새 val_id 로 넘기고, val1 에서 G6 를 떨어진 logic_hash 의 재검증을 금지해야 한다(§6).
6. **Forward 를 1차 증거로 쓰는 안**: 권하지 않는다. 확인 단계(G8·인큐베이션)로 유지한다.
   Forward 는 달력 시간으로만 쌓인다. 참 Sharpe 2 를 k=1·검정력 80% 로 보려면 약 1.1년, k=5 에서는 약 2.1년이 걸린다.
   그리고 Forward 는 다음 잠금 구간이 될 데이터라서, 많은 후보를 그 위에서 1차 평가하면 lb2 가 노출된다.
   대안은 저회전 후보용 '느린 차선'이다. 사전등록한 순차 검정으로, Forward 관찰 목록(사람 승인)에서 운영한다(§5).

## 1. 질문과 현재 상태

- 현재 분할: Dev 2021-01..2025-11(4.83년) · Val `val1` 2025-11..2026-05(6개월, 사용 2/20, 에이전트는 결과 코드만 앎) ·
  Lockbox `lb1` 2026-05..2026-11-08(개봉 0/10) · Forward 2026-11-09..
- 롤링 규칙: 잠금 10회 개봉 → lb1 을 Dev/Val 로 편입하고 쌓인 Forward 를 새 잠금으로 삼는다. Val 20회 사용 → Val 은퇴(Dev 편입), 새 Val.
- 질문: 다음 롤링에서 Val 을 12개월로(Dev 는 그만큼 짧게) 하면 저회전·중회전 전략의 검정력과 오탐이 어떻게 바뀌나?
  누적 Val Holm 효과는? Forward 를 1차 증거로 쓰는 안은?
- 비교 설계: 다음 롤링 시점에 쓸 수 있는 데이터(2021-01..2026-11)를 고정하고 나누는 방식만 바꾼다.
  **A = Dev 5.33년 + Val 6개월(2026-05..11)** vs **B = Dev 4.83년 + Val 12개월(2025-11..2026-11)**.
  합성 데이터 구간이 같으므로 같은 seed = 같은 시장이다. 그래서 A·B 를 시장끼리 짝지어 비교했다.

## 2. 방법 (3 층)

1. **해석적**: Val 평균 > 0 검정의 z ≈ Sharpe·√T. 누적 Holm 에서 k 번째 사용의 문턱은 앞선 사용이 귀무에 가까울 때 α/k = 0.10/k 다
   (지금까지 실제 사용은 모두 fail 이라 이 가정이 현실적이다).
2. **G6 단계 몬테카를로** (`scratchpad g6mc.py`, 셀마다 300회).
   - 판정은 실제 함수로 한다: `metrics.sharpe`/`max_drawdown`, `montecarlo.worst_case_mdd95`, `inference.bootstrap_mean_test`.
   - 거래 모형: Poisson(f/일) 청산, 거래 수익 = μ + σ_t·t(4). σ_t = 2.88%·√보유일(연 55% 시장).
     보유일은 f 0.2 → 3일, 0.5 → 1일, 1 → 0.5일, 5 → 1시간. stress 는 거래당 −4bp, 포지션은 전액 또는 절반.
   - Dev 관문은 없다. G6 만 본다.
3. **전체 파이프라인 짝 비교** (`calibration_study`, 새 기본 꺼짐 선택지). G0~G6 와 견고성 묶음까지 실제와 같다. G2 귀무 1,000, top_k 5, 새 원장(k=1).
   - 시나리오 3개, 세기마다 시장 8개, 분할 A·B:
     - **저회전** `5m_low`: donchian(288) 돌파 뒤 1일 드리프트(평균 중립). S* = donchian(288), SL 6%/TP 10%/1440분, 하루 0.45회. 격자 l12.
     - **초저회전** `5m_vlow`: 3일 드리프트. S* = SL 10%/TP 20%/4320분, 하루 0.23회. 격자 v12.
     - **중회전**: 기존 S*, donchian(48) SL 1%/TP 1.2%/60분, 하루 약 5회. 격자 g12.
   - "통계 조건만" = Dev 통과 ∧ Val Sharpe > 0 ∧ stress Sharpe > 0 ∧ p ≤ 0.10/k. MDD 두 조건은 뺀다.
     "현재 규칙(k)" = 여기에 primary MDD ≤ 20% ∧ MC MDD95 ≤ 20% 를 더한다. k > 1 은 S* 대표의 p 에 사후로 적용했다(견고성 묶음은 k=1 validated 열에만 반영).

**12개월에서만 7곳, 6개월에서만 0곳**이다. k=5 에서는 7곳 / 0곳이다.
현재 규칙 기준으로는 12개월에서만 통과한 시장이 0곳, 6개월에서만 통과한 시장이 4곳이다(모두 MC MDD95 때문).
귀무 시장(48개, 세 시나리오 × 2 분할)에서는 Dev 를 통과한 S* 가 없었다(G2 가 거의 모두 막음). 그래서 분할에 따른 오탐 차이는 이 표본에서 관찰되지 않는다.
저회전의 Dev 통과(S*)는 B(짧은 Dev)에서 같거나 오히려 많았다(저회전 Sharpe 1: 2 → 5, Sharpe 2: 5 → 6, 초저회전 Sharpe 2: 5 → 6).
차이는 G5·G2 경계 사례였고, 8개 시장 표본이라 잡음 범위다. Dev 를 6개월 줄여서 생기는 체계적 손실은 보이지 않는다.

| G1 ≥ 300 거래 | 하루 ≥ 0.154회 필요 | 하루 ≥ 0.170회 | 0.15~0.17회/일 전략만 경계. 0.2회/일 = 389 vs 353 거래 (둘 다 통과). 최근 12개월 ≥ 60 = 하루 0.16회 (같음) |
| G4 6개월 롤링 창 | 약 59창 | 약 53창 | 비율 기준이라 영향 작음 |
| G5 DSR | Sharpe 2 의 t ≈ 4.6 | ≈ 4.4 | 작음 (N_eff 1~10 에서 DSR 0.95 경계는 Sharpe ≈ 1.3–1.5) |
| 가중 Sharpe(반감기 365일) | Dev 끝 = 2026-05 | 2025-11 | 최근 1년 가중의 기준 시점만 이동 |

## 4. 누적 Val Holm

- 문턱은 k 번째 사용에서 0.10/k 다(앞선 사용 p 가 크면). val1 은 이미 2회 사용이라 다음 후보는 k=3 이고 문턱은 0.033 이다.
  지난 보정에서 캠페인 10개당 Val 사용은 약 7회였다. 캠페인 25~30개면 cap 20 에 닿는다.
- k 가 클수록 12개월의 상대적 이득이 커진다. 해석적으로 참 Sharpe 2 의 검정력은 다음과 같다.
  - k=3: 0.34 → 0.57 (×1.7)
  - k=10: 0.18 → 0.37 (×2.1)
  - k=20: 0.12 → 0.28 (×2.3)

  MDD 조건을 그대로 둔 MC 현재 규칙에서도 k ≥ 10 에서는 12개월이 앞선다(절반 포지션 f 0.5: 0.23 → 0.35).
- Val 길이는 Holm 의 오탐(가족별 오류)을 바꾸지 않는다. 바뀌는 것은 검정력뿐이다.
- 함께 볼 점: 12개월 Val 은 cap 20 을 다 쓰는 데 걸리는 기간이 같아도 데이터 6개월이 Dev 에 들어가지 않는다.
  그래서 Dev 성장이 Val 롤링 주기마다 6개월씩 늦어진다.
- 국면: 6개월 Val 은 국면 하나(예: 하락장)에 통째로 걸릴 확률이 높다. 합성 국면 보정(`calibration_regime_20261110.md`)에서는 Val 국면을 ⅓ 하락으로 순환시켰다.
  12개월은 국면 복권 효과를 줄인다. 롱 온리 저회전 전략에 특히 그렇다. 이 효과는 이번 표준 GARCH 시장에서는 재지 않았다.

## 5. Forward 인큐베이션을 1차 증거 단계로?

- 통계적으로 Forward T 년은 Val T 년과 같은 검정력을 준다(§3.1). 다만 달력 시간으로만 쌓인다.
  참 Sharpe 2 를 k=1·80% 로 보려면 약 1.1년, 여러 후보를 Holm 으로 묶으면(k=5) 약 2.1년이다. Sharpe 1.5 면 2~4년이다.
- Forward 는 노출이 없는 유일한 데이터이고 실제 체결·지연을 함께 본다(G8). 하지만 지금 규칙에서는 **다음 잠금 구간(lb2)이 될 데이터**다.
  많은 후보를 Forward 에서 매일 1차 평가하면 lb2 가 그 후보들의 성과에 노출된다. 이미 validated 후보 인큐베이션은 그렇게 하고 있다.
  1차 증거로 쓰려면 Forward 를 잠금으로 넘기는 규칙을 바꾸거나, Forward 평가를 결과 코드만으로 제한해야 한다.
- 권고:
  - Forward 는 확인 단계(G8, validated 인큐베이션)로 유지한다.
  - 저회전 후보 가운데 G6 를 '검정력 부족'으로만 떨어진 후보만 별도 차선에 올린다. 조건은 Val Sharpe > 0, stress Sharpe > 0, MDD 조건 통과, p 가 문턱과 0.2 사이다.
    이 차선은 **사전등록한 순차 검정**으로 운영한다. 예: 알파 지출(O'Brien-Fleming)로 분기마다 Forward 평가, 최대 2년, 후보 수만큼 Holm.
    `config/forward_watchlist.yaml`(사람 전용)이 이미 그 그릇이다. 이 차선은 validated 를 주지 않고 '관찰'만 한다.

## 6. 잠금 구간·롤링 함의 (다음 롤링 시)

| 안 | Dev | Val (새 val_id) | 새 잠금 | 장점 | 문제 |
|---|---|---|---|---|---|
| A. 6개월 유지 | 2021-01..2026-05 (val1 편입) | lb1 = 2026-05..11 | 쌓인 Forward | 지금 규칙 그대로. Dev 가 6개월 자람 | Val 검정력 낮음(§3.1) |
| B. 12개월 = val1 + lb1 | 2021-01..2025-11 (그대로) | 2025-11..2026-11 | 쌓인 Forward | 롤링 시점 그대로 가능 | val1 절반이 이미 사용됨(2회 이상, 결과 코드 공개). 새 val_id 는 Holm 원장과 'logic_hash 재사용' 규칙을 초기화한다 → val1 에서 떨어진 스펙을 같은 데이터가 섞인 Val 에서 다시 통과시킬 수 있음(골대 이동). Dev 가 자라지 않음 |
| C. 깨끗한 12개월 | 2021-01..2026-05 | lb1 + Forward 첫 6개월 = 2026-05..2027-05 | 2027-05 이후 Forward (≥ 6개월이면 롤링 ≥ 2027-11) | 노출 없는 Val | 롤링이 1년 늦어짐. 그 사이 Forward 인큐베이션이 Val 이 될 구간을 봄 |

- B 를 택한다면 최소 조건 두 가지가 필요하다. (1) 새 Val 의 Holm 에 val1 의 사용 p 를 이월한다(k 가 이어짐).
  (2) val1 에서 G6 를 떨어진 logic_hash 는 새 Val 에서 재검증을 금지한다(파이프라인 Val 재사용 규칙의 val_id 범위 확장).
  둘 다 사람의 코드·설정 변경이다.
- 어느 안이든 lb1 은 Dev 나 Val 이 된다. lb1 이 10회 개봉으로 은퇴한다면 그 10회의 결과만큼 이미 쓴 데이터다.
  lb1 의 기술통계가 Phase 0 에 노출됐다는 사실(PLAN 공개 사항)도 그대로 따라간다.
- **잠금 개봉의 Holm(G7)은 잠금 길이(약 6개월)에 묶여 있다.** Val 을 12개월로 늘려도 G7 의 검정력은 그대로다.
  Val 이 통과시킨 후보가 6개월 잠금에서 같은 문제(§3.1 의 6개월 열)를 다시 겪는다. 잠금도 12개월로 늘리려면 Forward 가 12개월 쌓일 때까지 롤링을 미뤄야 한다.

## 7. 사람에게 남기는 결정 항목 (이 노트는 결정하지 않음)

1. Val 길이(분할, 사람 편집): **MDD 조건의 경로 길이 정규화와 함께라면 12개월. 아니면 6개월 유지.**
2. G6 MDD 조건의 경로 길이 정규화(class ③, `preferences.option_table` 경로). 낙폭을 전액 포지션으로 평가한다는 점(저회전 장기 보유에 결정적)도 함께 본다.
3. 12개월로 간다면 B·C 중 선택. B 라면 Holm 이월과 재검증 금지가 필요하다.
4. Forward '느린 차선'(관찰 전용, 사전등록 순차 검정) 운영 여부.

## 8. 한계

- 셀마다 시장 8개라 짝 비교의 비율 구간이 넓다(8 중 0 의 Wilson 상한 32%). MC 셀은 300회다.
- 저회전 합성 엣지는 평균 중립으로 심은 '돌파 후 1일/3일 드리프트' 한 가지다.
  파일럿에서 귀무(k=0) S*_low 의 Sharpe 가 +0.42 로 나왔다(6년 × 4 seed, 잡음 또는 GARCH 꼬리 효과). 그래서 Sharpe 1 수준의 k 는 부정확하다.
- G6 MC 의 거래 모형은 SL/TP 절단과 국면이 없는 단순화다. 국면 복권 효과(§4)는 재지 않았다.
- 누적 Holm 효과는 S* 의 p 에 문턱 0.10/k 를 사후로 적용해 근사했다. 앞선 사용이 엣지 있는 후보라면 문턱이 더 느슨해진다.
- 비용 v2 는 잠정값이다.
