## 1. 왜 다시 보나

단계별 승격(D23)에서 G7 은 '페이퍼 진입 조건'이 아니라 **실제 자금(T2, 총자본 10%) 투입 조건**이 됐다. 지금 G7 은 잠금 6개월
**단독 유의성**(누적 Holm α 0.10)이라, 검증 구간에서 R1 이 고친 것과 같은 문제(6개월 단독 검정의 낮은 검정력)가 있다.

## 2. 실험

- 합성 5분 시장을 잠금 구간 끝까지 생성(Dev 4.8년 + Val 6개월 + **잠금 6개월**, 실제 분할과 같은 길이): 귀무 150 · 심은 엣지
  참 Sharpe 1.5 / 2 / 3 각 25 = **225 시장**. 현재 관문(R1+plus+크기 조절, camp-000032 기준)으로 캠페인·파이프라인 실행 →
  Dev 생존 후보마다 잠금 구간 일간 수익(같은 엔진·비용·MTM)을 계산해 세 규칙을 비교했다.
  - **holm** (현재): 잠금 일평균 > 0 의 부트스트랩 p ≤ 0.10 (시장마다 첫 개봉)
  - **no_contradiction**: 잠금 Sharpe > 0 ('모순 없음')
  - **combined**: (z_dev + z_val + z_lb)/√3 의 p ≤ 0.05 그리고 잠금 Sharpe > 0

## 3. 결과

- 귀무 시장 150개 중 **검증 통과 0** (R1 의 오탐 ≈ 0.4% 와 일치) → 귀무 쪽 비교는 이 표본에서 0/0 이다.
- **심은 엣지**: 현재 Holm 은 검증을 통과한 진짜 후보의 33% (17/52)를 잠금에서 떨어뜨린다 → Sharpe 2 최종 검출 72% → **40%**.
  '모순 없음'과 '결합'은 52/52 통과 (잠금 Sharpe 중앙값 2.5, 최소 0.003).
- 귀무 후보가 검증을 잘못 통과했을 때 잠금이 걸러 주는 비율(해석적, 잠금 수익이 독립·평균 0 이라고 볼 때):
  holm ≈ 90% 차단(p ≤ 0.10 통과 10%), no_contradiction ≈ 50% 차단, combined ≈ 50~70% 차단(검증 통과 후보의 Dev+Val z 가
  클수록 no_contradiction 과 같아짐; 이번 심은 후보의 z_dev+z_val 최소 5.2·중앙값 7.9 → 사실상 같음).
- 끝단 오탐(시장당, 승격 T2 까지): R1 ≈ 0.4% × {holm 0.1, no_contradiction 0.5, combined ≈ 0.3~0.5} ≈ **0.04% / 0.2% / 0.1~0.2%**.
