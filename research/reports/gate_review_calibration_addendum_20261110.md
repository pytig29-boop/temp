# 관문 재검토 합성 보정 — 추가 표: '크기 조절' 하한 0.25 / 0.5 (Phase 2)

작성 2026-11-10 · 분류 ② 증거 기준 + ③ 위험 선호(하한) · **근거는 합성 시장뿐이다** (실제 캠페인·Val·잠금 구간 결과 미사용)
· 원 리포트 `research/reports/gate_review_calibration_20261110.md` 의 원시 기록(시장 652개, 같은 기록)을 그대로 쓰고,
오프라인 평가기(`btc_quant.research.gate_review_study`)에 새로 넣은 **크기 조절 모드**(`g6_dd_mode="size"`, `g6_min_scale`)로 다시 계산했다.

## 1. 무엇을 쟀나

원 리포트의 R1 표에서 '크기 조절' 열은 **크기를 얼마든지 줄일 수 있다**는 상한(낙폭 조건 없음)이었다. 실제 규칙은
`position_scale = min(1, 0.20 / Val MDD, 0.20 / MC MDD95)` 이고 **배수가 하한보다 작으면 탈락**이다(사용자 결정 Q2: 하한 25%).
하한 0.25 와 0.5 에서의 정확한 오탐·검출을 계산했다.

## 3. 해석

- **하한 0.25 는 '상한(낙폭 조건 없음)'과 같은 결과다.** 이번 합성 시장에서 배수가 0.25 아래로 내려간(낙폭이 한도의 4배를 넘는)
  후보는 다른 관문에서 이미 떨어졌다. 하한 0.5 는 S2 검출을 2%p, S3 를 7%p 낮추고 오탐은 그대로다.
- **중단 조건 미발생**: R1+plus+크기 조절(0.25) 의 전체 오탐 0.4% (≤ 5%), 어려운 귀무 오탐 1/74 (원 리포트와 같음, 기준 ≥ 4/74 아님).
- 오탐 1건은 원 리포트와 같은 시장이다(낙폭 조건을 풀면 나타나는 1건, 증거 관문은 통과).
- 1분·ATR(하루 12회 이상 거래) 엣지는 여전히 0/42 — 원 리포트 §4.2-4 그대로(비용 ×1.5 견고성, 실제 취약성).

## 4. 한계

- 원시 기록은 Phase 1 의 MTM 파산 규칙 수정 **이전** 엔진(연구 프로세스 안 0-나눗셈 가드)으로 모였다. 두 규칙은 자산이 0 이하가
  되는 경우에만 다르고, 그런 스펙은 Dev 관문(G1~G5)을 통과하지 못하므로 위 표는 바뀌지 않는다. 실제 파이프라인과의 일치 점검(§5)은
  수정된 엔진으로 새로 모은 시장에서 했다.
- 크기 조절의 낙폭 축소는 '수익 × 배수'의 근사다(복리 경로에서 실제 낙폭은 배수 × 낙폭 이하).
