## 1. 프로필 (docs/MANAGED_HOLD.md Q1~Q11 에 대한 답)

모든 증거를 **동일 비중 3코인 B&H 대비 능동 수익**(전략 − B&H, 일간)에서 본다 — 절대 Sharpe 는 베타(상승 표류)만으로도 통과하기 때문.

| 관문 | 규칙 | 질문 |
|---|---|---|
| G1 | 풀링 전환(진입) ≥ 30, Dev ≥ 365일 | Q1 |
| G2 | **타이밍 귀무**: 자산별 일간 노출 상태열을 무작위 원형 이동 500회(노출·전환 수·보유 구간 길이 보존) → 능동 Sharpe 상위 5% **그리고** 순 능동 Sharpe > 0 | Q2 (a) |
| G3 | 인접(span·band) 능동 Sharpe 중앙값 ≥ 0.25 × 선택 | Q3 |
| G4 | 6개월 롤링(30일 간격) 능동 수익 ≥ 0 비율 ≥ 0.5 | Q4 |
| G5 | 능동 수익 DSR ≥ 0.95 (시도 = 격자 4) | Q5 |
| G6 | Val 능동 결합 증거(Dev 능동 DSR z + Val 능동 p, Stouffer) ≤ 0.05·Val 능동 Sharpe > 0; 낙폭 = 크기 조절(하한 0.25); B&H 대비 MDD 비 보고 | Q6 |
| 견고성 | 기존 묶음(지연·상위 거래·연도·비용 ×1.5), 알파·국면 비중은 정보 전용(베타 노출이 목적이므로) | — |
| G7 | 기본 프로필과 같은 방식(G7 결정 따름) | — |
| G8 | 기간 기준: 페이퍼 ≥ 8주 + 백테스트 노출 상태 일치율 ≥ 95% (거래 수 아님) | Q7 |
| 선별 | 템플릿의 선별 그대로(추세 on 이후 수익 > 매칭 귀무). '피하는 가치'는 G2 타이밍 귀무가 맡음 | Q8 |
| 위험 한도 | 사용자 결정(③)으로 따로 — 단계별 승격(T2 10%)과 크기 조절이 적용 | Q9 |
| 계열 | 새 계열 `managed_hold` (시도 수 별도) | Q10 |
| 성공 기준 | 위 관문 = 사전 등록 기준. MDD 비 0.6·포착 0.5 는 **보고용**(관문 아님) | Q11 |

## 2. 합성 보정

시장: 3코인(공통 요인 상관 ≈ 0.6) GARCH·t 1분봉 + **공통 국면 표류** ±μ/일, 국면 길이 기하분포(평균 L일). 격자 = 준비된 템플릿
(span 90/180 × band 0/100, 4 스펙), Dev 4.8년·Val 6개월, MTM, 자산별 비용. 시나리오별 40 시장 = **160 시장**.

- 귀무(추세 필터가 무의미): L = 1일 — null_flat(μ = 0), null_switch(μ = 0.3%/일, 매일 무작위 방향)
- 심은 추세 지속: L = 45 / 90일, μ = 0.3%/일

| 시나리오 | 시장 | Dev 통과 | 검증 통과 | 첫 실패 분포 | Dev 능동 Sharpe 중앙값 | Val MDD / B&H MDD 중앙값 |
|---|---|---|---|---|---|---|
| null_flat | 40 | 0 | 0 | G2 30, G3 2, G4 3, G5 5 | -0.41 | 0.73 |
| null_switch | 40 | 0 | 0 | G2 33, G3 3, G4 1, G5 3 | -0.38 | 0.70 |
| trend_L45 | 40 | 6 | 2 | G2 7, G3 6, G4 9, G5 12, G6 4, validated 2 | 0.35 | 0.66 |
| trend_L90 | 40 | 7 | 5 | G2 7, G3 4, G4 10, G5 12, G6 2, validated 5 | 0.38 | 0.59 |

전체 귀무 오탐: 0/80

- **오탐 0/80** (목표 ≤ 5%) — 귀무는 대부분 G2(타이밍 귀무)에서 떨어진다(63/80).
- 심은 추세 지속 시장에서 **G2 는 33/40 을 타이밍 가치로 식별**하지만, 능동 Sharpe 가 약해(중앙값 0.35~0.38) 4.8년 Dev 에서
  DSR ≥ 0.95(능동 DSR 중앙값 0.70~0.73)를 넘기 어렵다 → 최종 검출 2/40 (L45), 5/40 (L90).
- 민감도(같은 기록, Dev 통과 수): G5 0.95 → 0.90 이면 L45 6 → 7, L90 7 → 9, 귀무 0 그대로; 0.80 이면 귀무 3/80 이 Dev 를 통과.
  G4 0.5 → 0.4 는 차이 없음.
- Val MDD / B&H MDD 중앙값: 심은 시장 0.59~0.66 (낙폭 축소 효과), 귀무 0.70~0.73.

## 3. 권고와 결정 요청

- 프로필을 **위 기본값 그대로** 승인 (오탐 0/80). 약한 타이밍 효과는 이 기간으로 확인되지 않는다는 결과를 받아들인다.
  선택지: G5 를 0.90 으로(귀무 0/80 유지, 검출 소폭 증가).
- 승인 후 할 일(다음 캠페인부터): `gates.yaml` 에 `profiles.managed_hold` 추가, 캠페인 템플릿 `gate_profile: managed_hold` 를
  매니페스트에 고정, 파이프라인이 이 프로필이면 `managed_hold_gates.evaluate` 로 판정(Val 사용 기록·상한·재사용 규칙은 같게),
  테스트(기본 프로필 불변) → 준비된 템플릿으로 선별 → 첫 캠페인.
- 함께 해결: 4h EMA 워밍업 상한 120 → 420일 (페이퍼·전진에서 EMA(180) 정확 재현, 잔존 가중 ≈ 7e-13).

재현: `python -m btc_quant.research.managed_hold_study run --raw DIR --n 40` → `analyze`.
