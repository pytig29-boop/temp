## 요약

- **오탐률(목표 ≤ 5%)**: 귀무 90 시장(국면 60 = 하락 Val 20 + 표준 30)에서 모든 변형 조합 **0/90 = 0% [0–4]**, 하락 Val 귀무
  **0/20 [0–16]**. 귀무 시장의 상위 후보(99개)는 비용 후 Dev 손익이 모두 ≤ 0 이라 알파·국면 검사 모두 0% 통과 — 이 격자에서는
  G2 가 이미 다 막는다.
- **검정력(참 연 Sharpe 2, 국면 필터 엣지 S*_f 30 시장)**: 현재 관문(exposure_aware OFF)에서 국면 검사 방식 5종 × G4 최근 조건
  3종 **모두 23% [12–41]** — 증가 0%p. 국면 검사는 끝까지 간 S* 대표(G6 통과 9개)에서 한 번도 묶지 않았다(최대 손익 비중
  0.36~0.67). 국면 집중 후보는 그 전에 G4(최근 하락장)·G6(하락 Val)에서 이미 떨어진다.
- **G4 '쉼' 변형(최근 참여일 < 10%/25% 이면서 총수익 ≥ −2%)은 한 번도 적용되지 않았다.** 최근 12개월 Sharpe 조건만 걸린 S*
  대표 6개의 최근 참여일은 30~64%, 최근 수익 −3%~−41% — 추세 필터가 새서 하락장에서 '쉬지' 않고 잃는다. 이 실패는 조건이
  '쉬는 전략'을 벌한 것이 아니라 실제 손실을 잡은 것이다.
- **exposure_aware(노출 인식 G4/G6, 기본 OFF)를 켜면** 국면 검사가 묶는다: S* 대표 2개가 국면 검사만으로 실패(최대 비중 0.81·0.77,
  지배 국면 노출-맞춤 초과 +1.19·+1.43/년). 국면 검사를 완화하면 검정력 23% → 0.80: 27%, 0.90·dominant_alpha·informational: **30%
  (+7%p)**, 오탐 0/90 그대로. **목표 +10%p 미달**(그리고 두 기준을 동시에 바꾸는 조합이라 한 번에 한 기준 규칙에도 맞지 않음).
- **베타 탐침(조건부 진단)**: 귀무 시장 90개에서 저회전 장기 보유 롱 스펙(8개 × 90 = 720 후보; 국면 지속성이 만드는 '국면 타이밍'
  손익) 중 **G2 와 알파를 모두 통과한 귀무 후보 12개(6/90 시장)를 현재 국면 검사가 전부 막았다**. dominant_alpha·informational 은
  12개 모두 통과시킨다(0.80: 1개, 0.90: 3개). 즉 국면 검사는 이 유형에서 알파·G2 너머의 **유일한 방어선**이다.
- **결론: 목표(오탐 ≤ 5%, 하락 Val 오탐 ≤ 5%, Sharpe 2 검정력 +10%p)를 만족하는 변형 없음 → class ② 제안 없음.**
  `propose_criterion("robustness.regime_mode", ["dominant_alpha","informational"], …, study="regime")` → `no_change`,
  `propose_criterion("robustness.regime_max_pnl_share", [0.8, 0.9], …, study="regime")` → `no_change`
  (`research/reports/criteria_robustness_regime_mode_20261110_regime.md`, `…_regime_max_pnl_share_20261110_regime.md`).
  G4 최근 조건 변형은 관문 코드(gates.py)에 없는 보정 전용 반사실이라 제안 대상도 아니다(효과 0).

- 변형:
  - **국면 검사 방식** (`RCHECK_MODES`): `current`(비중 > 0.70 → 실패) · `share80` · `share90` · `dom_alpha`(새 옵션
    `robustness.regime_mode: dominant_alpha` — 비중 > 0.70 이면 그 지배 국면 안에서 전략 평균 일간 수익 − 그 국면 평균 보유 비율 ×
    BTC 평균 일간 수익(연율) ≥ 0 이면 통과; 총손익 ≤ 0 은 여전히 실패) · `info`(`informational` — 표시만).
    견고성 묶음은 G6 통과 후보에만 돌고 원장·Val 에 되먹이지 않으므로 같은 파이프라인 결과에 **사후 적용**
    (`robustness.regime_verdict`, check_regime 과 같은 함수). 사후 `current` 판정 = 파이프라인 라벨: 불일치 0건.
  - **G4 최근 12개월 변형** (`G4_RECENT_VARIANTS`): `g4flat10` = 최근 Sharpe > 0 **또는** (최근 12개월 시장 참여일 < 10% 이면서
    최근 총수익 ≥ −2%), `g4flat25` = 참여일 < 25%. 롤링 조건은 그대로. Dev 생존·Val 사용이 바뀌므로 **복사한 원장에서 파이프라인
    재실행**. 관문 코드는 바꾸지 않고 보정 프로세스 안에서만 `check_g4` 를 감싼 반사실이다.
  - 추가 파이프라인 변형 `ea_on`(exposure_aware.enabled true), `ea_on_g4flat10` — 같은 시장, 별도 실행(`--rcheck-variants`).
- 목표(고정, 실행 전): 귀무 전체 오탐 ≤ 5%, 하락 Val 귀무 오탐 ≤ 5%, S*_f 검정력 현재 대비 +10%p 이상 (Sharpe 2).
  오탐 = 귀무 시장에서 validated(견고성 포함) ≥ 1. 검정력 = 심은 스펙 또는 상관 ≥ 0.5 군집 대표가 validated.
- 조건부 진단 두 가지(원장·Val 미사용): ① G4 current 실행의 상위 후보 전부에 Dev 견고성(이상치·연도 제외·국면·알파)
  ② **베타 탐침** `--rcheck-beta 60`: 귀무 시장 90개에서 격자 rb8(돌파 lookback {24,96} × 필터 {없음, 60일 EMA} × SL 5% · TP 10% ·
  최대보유 {1일, 3일}) 전 스펙의 G2(귀무 500회, p ≤ 0.05·가중 Sharpe > 0)·알파·국면 판정 — 저회전 롱이라 비용에 먹히지 않고
  국면 베타·국면 지속성으로 Dev 손익이 양수인 귀무 후보를 일부러 만든다.

최근 Sharpe 만 걸린 6 시장의 Dev 마지막 1년 하락 국면 비중은 44~74% — 60일 EMA 필터는 하락 국면에서도 30% 넘게 켜져 잃는다. '쉬어서 피함'을 인정하는
변형은 쉬지 않는 필터를 구하지 못하고, 구하려면 손실 허용치(−6%~−41%)·참여일 상한(> 35%)을 크게 넓혀야 하는데 그것은 실제
손실을 통과시키는 것이라 시도하지 않았다(목표를 보고 기준을 넓히는 것 = 합성 안에서의 골대 이동).

## 해석

1. **현재 관문에서 두 기준은 종단적으로 묶지 않는다**(검정력 변화 0, 오탐 변화 0). 국면 집중·최근 하락장 손실·하락 Val 약함은
   같은 원인(새는 필터 + 상승 국면 의존)의 다른 얼굴이고, G4·G6 가 먼저 걸러 낸다.
2. 국면 검사가 묶는 것은 exposure_aware 를 켰을 때뿐이고(+7%p), 그때도 목표에 못 미친다.
3. 국면 검사는 알파·G2 와 겹치지 않는 보호를 한다: 국면 지속성으로 버는 귀무 롱 후보(베타 탐침)를 현재 비중 규칙만 막는다.
   dominant_alpha 안(지배 국면 안 노출-맞춤 B&H 초과 ≥ 0)은 바로 그 국면 타이밍을 '알파'로 세므로 보호를 없앤다 — **대체안으로
   부적합**. 비중 0.80/0.90 은 일부(1/12, 3/12)를 통과시키며 검정력 이득은 현재 관문에서 0.
4. G4 최근 12개월 조건은 롱 온리 필터 전략을 '쉬었다고' 벌하는 것이 아니라 실제 최근 손실을 잡고 있었다(쉼 경로 적용 0건).

## 남는 일 (사람 결정)

- 제안 없음. `robustness.regime_mode` 는 `pnl_share`(기존 동작), `regime_dominant_min_excess` 0.0 으로 목록에만 추가(class ②).
- exposure_aware 를 나중에 켜는 제안을 다시 잴 때는 국면 검사와의 상호작용(+7%p 중 국면 검사 몫)을 함께 보고해야 한다 — 단,
  두 기준 동시 변경은 한 번에 한 기준 규칙에 따라 따로 제안·승인.
- 한계: S*_f 시장 30 → 검정력 구간 ±15%p. 베타 탐침은 조건부(Dev 견고성 단계)라 종단 오탐률이 아니다. 국면 시장의 '귀무'는 국면
  지속성을 포함하므로 그것을 엣지로 볼지(실제 BTC 의 추세 지속성)는 설계 판단이다 — 이 리포트는 '심은 엣지가 아님'으로 셌다.
