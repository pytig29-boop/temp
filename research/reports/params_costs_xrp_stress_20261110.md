# 코인원 XRP 스트레스 비용 상향 (Q7) — 근거

작성 2026-11-10 · 분류 ① 측정값 · 방향: **엄격(비용 상향)** · 사용자 승인: 2026-11-10 채팅 Q7 ("XRP 스트레스 14 → 약 20bp 상향 승인")

## 측정

- 표본: 실시간 WS 호가(코인원·업비트 XRP-KRW), 2026-11-10 04:45–11:05 UTC (약 6.3시간, 관측 시간대 8개, KST 13~20시),
  코인원 스냅샷 14,359개(양방향 28,718 표본), 업비트 17,447개. 주문 규모 30만 원(`calibration.notional_krw`).
- 도구: `btc_quant.params.calibrate` 의 같은 규칙(`load_orderbook_costs` → `estimate_venue`, 심볼만 XRP-KRW).
  표본이 72시간 미만이라 **잠정(provisional)**: 분위수의 시간 블록 부트스트랩 95% 상한을 쓴다(도구 기본 동작).
  스트레스 = p99 × 안전계수 1.5 (`calibration.quantiles.stress`, `calibration.stress_safety_factor`).

| | 편도 p50 | 편도 p99 | 스트레스 편도(규칙) | 스트레스 왕복 | 현재 모델 왕복 |
|---|---|---|---|---|---|
| 코인원 XRP | 3.39 bp | 7.58 bp | **11.88 bp** (상한 기반; 점추정 ×1.5 = 11.38) | **23.8 bp** | 14.0 bp (스프레드 6.7 + 슬립 3.65 ×2) |
| 업비트 XRP | 3.39 bp | 8.06 bp | 13.93 bp (+ 수수료 5bp) | 27.9 bp + 수수료 | 29.4 bp + 수수료 (스프레드 13.4, 슬립 8) |

- 게이트 재검토 리포트(§4.1)의 4시간 표본은 20.2 bp 였다. 표본이 약 6시간으로 늘면서 **23.8 bp** 가 됐다(같은 규칙).
  사용자가 승인한 것은 '실측 규칙에 맞춘 상향'(엄격 방향)이고, 분류 ① 측정값의 엄격 방향 갱신은 자동 허용이다(docs/PARAMS.md §1).
  그래서 4시간 값이 아니라 **현재 표본의 도구 산출값(23.8 bp)** 을 적용한다.
- 스프레드는 6.7 bp(1원 호가 단위, 중앙값 6.78)로 두고 슬립으로 조정: 슬립 = 11.88 − 6.7/2 = **8.53 bp**.
- 업비트 XRP 스트레스: 측정 편도 13.93 bp < 현재 14.7 bp(6.7 + 8) → **이미 더 엄격, 변경 없음**.
- 코인원 XRP 기본(8 bp)·보수(10 bp): 측정(6.8 / 6.9 bp)보다 이미 높다 → 변경 없음(하향은 72시간 표본 뒤 승인 절차).

## 영향

- `coinone_stress@XRP-KRW` 를 쓰는 곳: G6 스트레스 Val Sharpe(R1 적용 뒤에는 표시만), 견고성·보고의 스트레스 비용 열.
- 적용은 비용 레지스트리의 새 버전(v2). 이전 캠페인 재계산은 실행 기록의 비용 버전으로 재현 가능.
- 잠정값: 72시간 표본이 모이면 다시 측정한다(상시 실행 환경 필요, Phase 7).

원자료: 스크래치패드 `xrp_cost.json` (재현: `calibrate.SYMBOL="XRP-KRW"` 후 `load_orderbook_costs` · `estimate_venue`).
