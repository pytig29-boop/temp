어떤 구간을 보고 얻은 것인가"를 함께 적는다. 오답노트(`research/lessons/`)가 *우리 캠페인의 결과*라면,
이곳은 *캠페인 이전의 사전 지식*이다.

## 표기 규약 (모든 항목)
각 항목 끝의 태그:
- `src:` 출처 (리포트 경로·문서 절·측정 일시). 출처 없는 문장은 쓰지 않는다.
- `기간:` 근거 데이터의 기간 (UTC).
- `잠금:` **노출** = 잠금 구간(2026-05-01~11-08)을 본 결과 · **없음**
- `Val:` **노출** = Val 구간(2025-11-01~2026-04-30)을 본 결과 · **없음**
- `신뢰:` 측정(장기) · 측정(단기 표본) · 관찰(정성) · 가설(검증 안 됨)

## 사용 규칙
1. **잠금 노출 항목은 가설의 '동기'로만** 쓸 수 있다. 성공 기준·격자 선택의 근거로 쓰려면 먼저 Dev 구간에서
   신호 선별(`btc_quant.research.signal_study`)로 재확인한다. 이 계열 후보는 리포트에 노출 사실을 적는다
   (PLAN §11).
2. Val 노출 항목도 같다: Val 은 G6 에서 *처음 보는* 데이터여야 하므로, Val 에서 관찰한 패턴을 Dev 에서 고른 뒤
   Val 로 확인하는 것은 순환 논리다. 최종 판단은 Forward(페이퍼)가 한다.
3. 새 항목 추가: 출처·기간·노출 태그를 반드시 단다. Dev 구간에서 새로 측정한 수치는 `잠금: 없음, Val: 없음`.
4. 이 디렉터리는 AI 가 편집할 수 있다(사실 기록은 오답노트 API, 여기는 사전 지식). 수치를 바꿀 때는 이전 값과
   출처를 남긴다.
